This is a small, independently-run project, not a formally audited site, so there’s no certified compliance statement to give — but pages use semantic HTML, interactive elements are keyboard-operable, and search suggestions support arrow-key navigation. Some parts of the site, particularly maps and network diagrams, are inherently visual and don’t currently have a non-visual equivalent. If you hit a genuine accessibility barrier using this site, [please open an issue on GitHub](https://github.com/gjhilton/NorthRidingQuarterSessions/issues) — that’s the most reliable way to get it looked at.
